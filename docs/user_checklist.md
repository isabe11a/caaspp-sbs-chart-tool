# Nontechnical User Checklist

Use this checklist in workshops or emails.

1. Download CAASPP Smarter Balanced districtwide **All Student Groups** files.
2. Open the Colab notebook.
3. Run Step 1.
4. Run Step 2 and upload the CAASPP ZIP files.
5. Run Step 3 and enter district name, county code, district code, and output prefix.
6. Run Step 4 to make the table.
7. Run Step 5 to preview the table.
8. Run Step 6 to create the CSV and Excel files.
9. Run Step 7 to download the CSV and Excel files.
10. Upload either the CSV or Excel file to Google Sheets.

# Nontechnical User Checklist

Use this checklist in workshops or emails.

1. Download CAASPP Smarter Balanced districtwide **All Student Groups** files.
2. Open the Colab notebook.
3. Run Step 1.
4. Run Step 2 and upload the CAASPP ZIP files.
5. Run Step 3 and enter district name, county code, and district code.
6. Run Step 4 to process the files.
7. Run Step 5 to preview results.
8. Run Step 6 to create outputs.
9. Run Step 7 to download outputs.
10. Upload the Excel workbook to Google Sheets.
